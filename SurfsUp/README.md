Resources folder contains resources files
The SurfsUp folder contains the working project files.
app.py is the Python file used to run a development Flask application.
climate_starter.ipynb is a Jupyter Notebook file used for climate data analysis.

Instructions:

Clone the repository.
Open up climate_starter.ipynb inside Jupyter Notebook or Visual Studio Code to run analysis.
Run app.py and go to the given web address to open Flask API development server.
Append available routes listed to the URL to explore different pages.
